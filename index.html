European Football Injury Burden Dashboard

This project explores injury patterns across Europe’s top football leagues from the 2020/21 through 2024/25 seasons. The dashboard combines season timing, league-level injury burden, club drilldowns, and recovery-time patterns to help explain where injuries are concentrated.

Goal 1: make interactions obvious

Usability testing showed that hover, click, and filtering features need short instructions near the relevant chart.

Goal 2: keep values readable

Printed values, clear labels, and enough spacing help users answer tasks without guessing from color or position alone.

Goal 3: connect overview to detail

The dashboard starts with high-level league and season patterns, then uses drilldowns to explain what is driving the values.
